# Неисправности

| Симптом | Причина / что делать |
|---|---|
| Тишина при включении | сели батарейки → питание от USB-C; проверить тумблер, полярность диода, провода RAW/GND |
| «Готов» повторяется каждые 4 с | прошивка зависает, и watchdog её перезагружает. Проверить питание при срабатывании соленоида |
| «Готов» сразу после мелодии открытия | контроллер перезагружается от просадки напряжения при ударе соленоида. Сделать провода питания толще и короче, проверить батарейки |
| Щелчок есть, задвижка не втягивается | мало напряжения или тока. Проверить XY-MOS и соленоид напрямую от батареек |
| Задвижка отпадает между высоким и средним тоном (на второй секунде) | садятся батарейки, пора менять |
| Задвижка отпадает раньше даже со свежими батарейками | увеличить `SOL_END_DUTY` (60–70) или `SOL_FULL_MS` |
| Ни одна клавиша не щёлкает | разъём клавиатуры сдвинут или перевёрнут → проверить посадку, `KEYPAD_REVERSED` |
| Клавиши срабатывают не те | другая распайка у клона → поправить `ROW_PINS` / `COL_PINS` или `KEYMAP` |
| A, B, C, D не работают | так и задумано по умолчанию; включается `USE_ABCD 1` |
| Буззер молчит или хрипит | проверить `BUZZER_PASSIVE`: активный буззер при `1` хрипит, пассивный при `0` щёлкает |
| Длинный-короткий-длинный | память повреждена или изношена. Открыть ключом → [сброс кнопкой](usage.md#сброс-на-заводской-код-0000). Если повторяется, заменить Pro Mini |
| 5 быстрых писков при включении | выключен BOD (см. [фьюзы](firmware.md#фьюзы-bod)) |
| Замок в блокировке сразу после включения | так и задумано: блокировка продолжается после выключения питания. Подождать 5 минут |
| Забыли код | открыть ключом → [сброс на `0000`](usage.md#сброс-на-заводской-код-0000) → задать новый |
| Ошибки при компиляции или загрузке | см. [частые ошибки Arduino IDE](firmware.md#частые-ошибки-arduino-ide) |
