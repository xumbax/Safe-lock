# Прошивка

Залить прошивку можно двумя способами:

- **[Из исходников в Arduino IDE](#arduino-ide).** Нужен, если вы меняете [настройки](configuration.md).
- **[Готовым файлом .hex](#готовая-прошивка-hex).** Подходит, если устраивают настройки по умолчанию.

## Подключение USB-UART адаптера

Адаптер нужен на **3,3 В**. Если на нём есть джампер напряжения, поставьте его в положение 3V3.

| Адаптер | Pro Mini |
|---|---|
| GND | GND |
| 3V3 / VCC | VCC |
| TXD | RXI |
| RXD | TXO |
| DTR | DTR (иногда подписан GRN) |

- Если у адаптера нет вывода DTR, держите кнопку RESET на Pro Mini и отпустите её, когда в IDE появится «Загрузка…».
- Во время прошивки **отключите батарейки (тумблер OFF) и USB-C замка**: плата питается от адаптера.

## Arduino IDE

Подходят Arduino IDE 1.8.x и 2.x. Ставить сторонние библиотеки не нужно, используется только встроенная EEPROM.

1. Откройте `firmware/safe_lock/safe_lock.ino`. Папка должна называться так же, как скетч: `safe_lock`.
2. Выберите:

   | Параметр | Значение |
   |---|---|
   | Инструменты → Плата | Arduino Pro or Pro Mini |
   | Инструменты → Процессор | **ATmega328P (3.3V, 8 MHz)** |
   | Инструменты → Порт | порт адаптера |

3. Нажмите «Проверить», потом «Загрузить».
4. В конце лога должно быть `... bytes of flash verified`. После загрузки плата перезапустится и выдаст два писка «готов».

Настройки прошивки (тип буззера, раскладка клавиатуры, время удержания соленоида и т. д.) находятся в начале скетча, в блоке `НАСТРОЙКИ`. Описание всех параметров — в [configuration.md](configuration.md).

## Готовая прошивка (.hex)

В папке [`firmware/prebuilt/`](../firmware/prebuilt/) лежит прошивка, собранная с **настройками по умолчанию**:

- пассивный буззер (`BUZZER_PASSIVE 1`);
- watchdog включён (`USE_WATCHDOG 1`);
- проверка BOD включена (`CHECK_BOD 1`);
- клавиатура: вывод 1 на D2 (`KEYPAD_REVERSED 0`), A–D не используются (`USE_ABCD 0`);
- соленоид: 1 с полный ток, затем 2 с спад ШИМ со 100 % до 50 %, тон в конце каждой секунды;
- заводской код `0000`.

Если вам нужны другие настройки, соберите прошивку из исходников в Arduino IDE.

**Загрузка через avrdude** (входит в Arduino IDE; `COM9` замените на свой порт):

```
avrdude -c arduino -p m328p -P COM9 -b 57600 -U flash:w:safe_lock_v2.2_promini-3v3-8mhz.hex:i
```

Загрузчик Pro Mini 8 МГц работает на скорости **57600**. На Windows можно использовать и графическую программу XLoader: выберите в ней устройство с ATmega328 и скорость 57600.

Контрольная сумма файла записана в [`firmware/prebuilt/SHA256SUMS`](../firmware/prebuilt/SHA256SUMS).

## Фьюзы: BOD

**BOD** (brown-out detector) держит контроллер в сбросе, когда питание просело. Без BOD при медленно садящихся батарейках процессор может выполнить случайную команду и, например, испортить EEPROM. В заводских Pro Mini BOD включён на 2,7 В (`efuse = 0xFD`), но у клонов бывает выключен.

Прошивка проверяет это сама: **5 коротких писков при каждом включении** означают, что BOD выключен. Включить его можно только программатором (USBasp и т. п.) через ISP-разъём:

```
avrdude -c usbasp -p m328p -U efuse:w:0xFD:m
```

Старые версии avrdude могут требовать `0x05` вместо `0xFD`: неиспользуемые биты фьюза они считают нулями. Без программатора замок работает и так, только предупреждение будет звучать при каждом включении. Отключить его можно параметром `CHECK_BOD 0`.

## Watchdog и старый загрузчик

Watchdog перезагружает контроллер, если прошивка зависла. Старый загрузчик ATmegaBOOT, который стоит на многих клонах (в логе avrdude он виден как `FW Version 1.16` на скорости 57600), после такой перезагрузки может уйти в бесконечный цикл.

**Проверка:**

1. Временно добавьте в начало `loop()` строку `while (1);` и прошейте.
2. Если через ~4 с после писка «готов» звучит ещё один «готов», и так каждые 4 с, всё в порядке.
3. Если плата замолчала навсегда, загрузчик не поддерживает перезагрузку от watchdog.
4. Уберите `while (1);` и прошейте снова.

**Если проверка не прошла**, для замка это не опасно. При зависании плата замолчит, соленоид останется выключенным, а выключение и включение тумблера всё вернёт. Можно оставить как есть, поставить `USE_WATCHDOG 0` или прошить загрузчик Optiboot программатором (Инструменты → Записать загрузчик).

## Частые ошибки Arduino IDE

| Ошибка | Причина и решение |
|---|---|
| `avr-g++: error: device-specs/specs-atmega328p: No such file or directory` | Компилятор Arduino распакован не полностью (часто из-за антивируса) или мешает переменная окружения `GCC_EXEC_PREFIX`. Удалите эту переменную (Win+R → `sysdm.cpl` → Дополнительно → Переменные среды). Затем переустановите «Arduino AVR Boards» через Инструменты → Плата → Менеджер плат, на время установки отключив антивирус. В портативной IDE можно удалить папку `portable\packages\arduino`, тогда IDE возьмёт встроенный компилятор |
| `'CodeData' does not name a type` | Старая версия скетча (до 2.1). Возьмите `safe_lock.ino` из этого репозитория |
| Все задержки вдвое длиннее, загрузка не идёт | выбран процессор «5V, 16 MHz». Нужен **3.3V, 8 MHz** |
| `stk500_recv(): programmer is not responding` / `not in sync` | не тот порт; TX/RX перепутаны; не подключён DTR (нажимайте RESET вручную); неверный процессор |
| Несколько библиотек найдено для `EEPROM.h` | это не ошибка, а информационное сообщение |
