# Настройки прошивки

Все параметры находятся в начале [`safe_lock.ino`](../firmware/safe_lock/safe_lock.ino), в блоке `НАСТРОЙКИ`. После изменения прошивку нужно собрать и загрузить заново (см. [прошивку](firmware.md)).

## Оборудование

| Параметр | По умолчанию | Описание |
|---|---|---|
| `BUZZER_PASSIVE` | `1` | `1` — пассивный буззер (разные тона), `0` — активный (сигналы различаются только ритмом) |
| `USE_WATCHDOG` | `1` | перезагрузка при зависании, см. [watchdog](firmware.md#watchdog-и-старый-загрузчик) |
| `CHECK_BOD` | `1` | предупреждение при выключенном BOD, см. [фьюзы](firmware.md#фьюзы-bod) |
| `KEYPAD_REVERSED` | `0` | `0` — вывод 1 клавиатуры на D2; `1` — разъём надет наоборот (вывод 1 на D9) |
| `USE_ABCD` | `0` | `1` — клавиши A, B, C, D можно использовать в коде |
| `ROW_PINS`, `COL_PINS` | D2–D5; D6–D9 | выводы клавиатуры (выбираются через `KEYPAD_REVERSED`) |
| `KEYMAP` | стандартная 4×4 | символы клавиш |
| `PIN_SOL` | 10 | соленоид. **Не менять**: ШИМ завязан на Timer1 (OC1B) |
| `PIN_BUZ` | 11 | буззер |
| `PIN_PROG` | 12 | кнопка программирования |

## Соленоид

| Параметр | По умолчанию | Описание |
|---|---|---|
| `SOL_FULL_MS` | 1000 | полный ток (100 %), мс |
| `SOL_RAMP_MS` | 2000 | плавный спад заполнения ШИМ после полного тока, мс |
| `SOL_END_DUTY` | 50 | заполнение в конце спада, %. `100` — без спада, полный ток всё время |
| `SOL_PWM_HZ` | 1000 | частота ШИМ. XY-MOS с оптроном работает не выше 1–2 кГц. Соленоид может слегка гудеть, это нормально |

Замок открыт `SOL_FULL_MS + SOL_RAMP_MS` = 3 с. Первую секунду соленоид получает полный ток, следующие 2 секунды заполнение ШИМ линейно спадает со 100 % до 50 %:

| Момент | ШИМ | Тон |
|---|---|---|
| `#` → мелодия → включение | 100 % | — |
| 0–1 с | 100 % | — |
| конец 1-й секунды | начинает плавно снижаться | короткий **высокий** |
| конец 2-й секунды | 75 % | короткий **средний** |
| конец 3-й секунды | 50 % | короткий **низкий** → соленоид выключен |

Отсчёт идёт с момента включения соленоида. В конце каждой секунды звучит один короткий тон: после первой — высокий (ШИМ начинает снижаться), после второй — средний (ШИМ 75 %), после третьей — низкий (ШИМ 50 %), и сразу после него соленоид выключается. Сигналы описаны в [usage.md](usage.md#сигналы-буззера).

По тонам слышно, когда отпала задвижка. Со свежими батарейками она держится до низкого тона. Если задвижка стала отпадать уже на второй секунде, между высоким и средним тоном, батарейки пора менять.

Постоянное заполнение 35 % задвижку с катушкой 16 Ом не удерживало даже на свежих литиевых батарейках, поэтому спад идёт только до 50 %. Проверьте на своём замке, что задвижка держится до низкого тона и от батареек, и от USB. Если нет, поднимите `SOL_END_DUTY` до 60–70.

## Тоны во время открытия

| Параметр | По умолчанию | Описание |
|---|---|---|
| `OPEN_TICK_MS` | 1000 | период отсчёта, мс: тон звучит в конце каждого периода |
| `OPEN_TONE_MS` | 15 | длина тона, мс (как щелчок клавиши) |
| `OPEN_TONES_HZ` | 2500, 2000, 1500 | частоты тонов после 1-й, 2-й и 3-й секунды, Гц |

## Код и защита

| Параметр | По умолчанию | Описание |
|---|---|---|
| `CODE_MIN_LEN` | 4 | минимальная длина кода |
| `CODE_MAX_LEN` | 8 | максимальная длина. Больше 8 нельзя без изменения раскладки EEPROM |
| `FACTORY_CODE` | `"0000"` | заводской код: 4–8 символов `0-9`, при `USE_ABCD 1` также `A-D` |
| `MAX_FAILS` | 3 | неверных попыток до блокировки |
| `LOCKOUT_MS` | 5 мин | длительность блокировки |
| `WRONG_DELAY_MS` | 1500 | пауза перед сигналом «неверно», мс |

## Время

| Параметр | По умолчанию | Описание |
|---|---|---|
| `REMIND_START_S` | 30 | через сколько секунд без нажатий начинается напоминание выключить тумблер |
| `REMIND_PERIOD_S` | 30 | период напоминания (точность ±10 %) |
| `PROG_TIMEOUT_S` | 30 | тайм-аут ввода в режиме смены кода |
| `FACTORY_RESET_HOLD_S` | 10 | сколько секунд держать кнопку для сброса на заводской код |
| `POWERUP_DELAY_MS` | 300 | пауза после включения до первой записи в EEPROM (дребезг тумблера) |
